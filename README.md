# AI-Powered-Data-Analysis-Remote-Internship
I have completed 4 week remote internship in Excelerate

Dataset Overview:
The dataset used in this project tracks student engagement and participation across various 
learning opportunities offered through the RIT platform.
Rows: 8,558 
● Number of variables (columns): 16 
● Unique opportunities: 23 
● Date range covered: 5 October 2022 – 11 March 2024 (Apply Date)

Model Training:
Two models were trained on this data. Logistic Regression reached 80.70% accuracy. Random Forest, an ensemble 
of 200 decision trees, reached 78.25% accuracy. Random Forest was carried forward because it also produces 
feature importance scores, which help explain which variables drive the predictions.
